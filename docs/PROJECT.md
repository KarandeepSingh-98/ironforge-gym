# IRONFORGE FITNESS — Project Description

## 1. Project Overview

IRONFORGE FITNESS is a professional, modern, responsive gym and fitness website.

The purpose of this project is to create a realistic gym website that could be used by a real fitness center to showcase its services, trainers, programs, membership plans, testimonials, and contact information.

This project will be developed in two versions:

### Version 1
HTML + CSS + Vanilla JavaScript

### Version 2
React + JavaScript

The goal is not only to build the website but also to use the project as a learning project for AI-assisted development and vibe coding.

---

# 2. Main Goal

Create a professional gym website that looks realistic enough for a real business.

The website should have:

- Professional visual design
- Responsive layout
- Clean typography
- Good spacing
- Modern cards
- Smooth animations
- Accessible HTML
- Working JavaScript interactions
- Clean and maintainable code
- Good mobile experience
- Good desktop experience

The final website should not look like a basic beginner template.

# 21. Development Philosophy

Build the project feature-by-feature.

Do not build the entire project blindly in one step.

For each feature:

1. Understand the requirement.
2. Inspect the existing project.
3. Create a plan.
4. Implement the feature.
5. Test it.
6. Fix problems.
7. Review the result.
8. Update PROGRESS.md.
9. Commit the completed work.
10. Move to the next feature.

The AI must not claim a feature is complete unless it has actually been implemented and verified.
