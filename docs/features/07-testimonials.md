# Feature 07 — Testimonials

## Objective
Build trust by showing realistic customer experiences.

## Requirements
Each testimonial should contain:
- Customer name.
- Photo/avatar.
- Rating.
- Testimonial text.
- Optional fitness goal.

## Example
"IRONFORGE completely changed my approach to training. The trainers actually care about your progress."

## Design
- Clean testimonial cards.
- Strong quotation styling.
- Rating should be visually clear.
- Avoid fake-looking excessive effects.

## Optional Enhancement
Version 1 may use a static grid.

React version may optionally implement a simple testimonial carousel.

## Acceptance Criteria
- Testimonials are readable.
- Cards are responsive.
- Rating is accessible and understandable.
- No excessive animation.
