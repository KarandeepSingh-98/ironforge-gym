# Feature 06 — Membership Plans

## Objective
Present clear membership options and encourage users to join.

## Plans

### Basic
- Gym access
- Locker access
- Basic equipment

### Pro
- Full gym access
- Group classes
- Fitness assessment
- Locker access

### Elite
- Everything in Pro
- Personal training
- Nutrition guidance
- Priority booking

## Requirements
- Display price.
- Display included features.
- Include CTA button.
- Highlight Pro as "Most Popular".
- Make pricing easy to compare.
- Responsive layout.

## Design
- Strong visual hierarchy.
- Featured plan should stand out without looking excessive.
- Clear CTA.

## Acceptance Criteria
- Plans are easy to compare.
- Features are readable.
- CTA buttons work.
- Mobile layout does not require horizontal scrolling.
