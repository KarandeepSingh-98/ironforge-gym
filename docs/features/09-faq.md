# Feature 09 — FAQ

## Objective
Answer common questions about IRONFORGE FITNESS using an interactive FAQ.

## Questions
1. What are your opening hours?
2. Do you offer personal training?
3. Can beginners join?
4. Do you offer trial sessions?
5. What membership plans are available?
6. Do I need to bring my own equipment?

## Requirements
- Question and answer pairs.
- Click/tap to expand.
- Click/tap to collapse.
- Clear open/closed state.
- Accessible buttons.
- Keyboard support.
- Avoid excessive animation.

## Version 1
Implement using Vanilla JavaScript.

## React Version
Implement using component state.

## Acceptance Criteria
- Questions open correctly.
- Questions close correctly.
- Multiple-open behavior should be intentionally chosen and documented.
- Keyboard users can operate the FAQ.
- No console errors.
