# Feature 01 — Navbar

## Objective
Create a professional, responsive navigation bar for IRONFORGE FITNESS.

## Requirements
- Brand/logo text: IRONFORGE FITNESS.
- Navigation links: Home, About, Programs, Trainers, Membership, Testimonials, Contact.
- Include a prominent "Join Now" CTA.
- Desktop navigation should display links horizontally.
- Mobile navigation should collapse into a hamburger/menu button.
- Mobile menu must open and close smoothly.
- Navigation should remain visually consistent across all sections.
- Use semantic HTML and accessible buttons.
- Keyboard users should be able to operate the mobile menu.
- Add a visible focus state.
- Use sticky/fixed positioning only if it improves UX.

## Version 1
Use HTML, CSS and Vanilla JavaScript.

## JavaScript
- Toggle mobile menu.
- Close menu when a navigation link is selected.
- Prevent broken navigation behavior.
- Support smooth scrolling where appropriate.

## Design
- Premium dark fitness aesthetic.
- Strong typography.
- Clear spacing.
- Subtle hover and active states.
- Responsive on desktop, tablet and mobile.

## Acceptance Criteria
- All navigation links work.
- Mobile menu opens and closes.
- No horizontal overflow.
- Keyboard interaction works.
- No console errors.
- Layout works at approximately 375px, 768px and desktop widths.
