# Feature 10 — Contact Section

## Objective
Give visitors a clear way to contact IRONFORGE FITNESS.

## Form Fields
- Full Name
- Email
- Phone
- Message
- Submit button

## Contact Information
Display:
- Address
- Phone
- Email
- Opening hours

Use realistic placeholder information for the demo project.

## Validation
Required:
- Name.
- Email.
- Message.

Email must have a reasonable email format.

Phone validation should be appropriate without being unnecessarily restrictive.

## Version 1
Frontend validation only. Do not connect to a real backend or send emails.

## User Feedback
Show:
- Validation errors.
- Success message after valid submission.

Do not claim that an email was actually sent.

## Design
- Professional contact layout.
- Form should be easy to use.
- Contact information should be easy to scan.
- Responsive on mobile.

## Acceptance Criteria
- All required fields validate.
- Invalid email is rejected.
- Valid submission produces clear feedback.
- No page reload is required if JavaScript handles the form.
- No console errors.
