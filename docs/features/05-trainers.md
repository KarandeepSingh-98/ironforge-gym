# Feature 05 — Trainers

## Objective
Showcase professional IRONFORGE FITNESS trainers.

## Example Trainers
- Alex Morgan — Head Strength Coach
- Daniel Carter — Personal Trainer
- Sophia Williams — Fitness Coach
- Marcus Reed — Performance Coach

## Each Trainer Card
- Professional image.
- Name.
- Position.
- Specialization.
- Experience.
- Optional social links.

## Requirements
- Consistent card design.
- Responsive grid.
- Accessible images with meaningful alt text.
- Clear typography.
- Optional hover interaction.

## React Version
Create a reusable `TrainerCard` component and store trainer information in a data file.

## Acceptance Criteria
- Trainer information is easy to scan.
- Cards work on mobile.
- Images are responsive.
- Social links, if present, are accessible.
