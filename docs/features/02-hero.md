# Feature 02 — Hero Section

## Objective
Create a high-impact hero section that immediately communicates the IRONFORGE FITNESS brand.

## Content
Headline:
"BUILD YOUR STRONGEST SELF"

Supporting text:
"Train smarter. Get stronger. Become the best version of yourself."

CTA buttons:
- Join Now
- Explore Programs

## Requirements
- Large, professional fitness/gym visual.
- Strong visual hierarchy.
- Responsive layout.
- Primary and secondary CTA buttons.
- Optional small statistics or trust indicators.
- Text must remain readable over the background.
- Do not overuse animations.

## Design
- Premium dark theme.
- Strong contrast.
- Large heading.
- Modern typography.
- Professional image treatment.
- Subtle entrance animations.

## Acceptance Criteria
- Hero is visually dominant.
- CTAs are clearly visible.
- CTAs navigate to the correct sections.
- Text remains readable on mobile.
- No layout overflow.
- Responsive across desktop, tablet and mobile.
