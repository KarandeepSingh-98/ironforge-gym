# Feature 04 — Training Programs

## Objective
Display the gym's major training programs in reusable cards.

## Programs
1. Strength Training
2. Muscle Building
3. Weight Loss
4. Personal Training
5. HIIT
6. Functional Training

## Each Program Should Include
- Image or icon.
- Program name.
- Short description.
- CTA or Learn More action.

## Requirements
- Use a consistent card design.
- Cards should be responsive.
- Use CSS Grid or Flexbox.
- Hover states should be subtle.
- Avoid excessive animation.

## Version 1
Use semantic HTML and reusable CSS classes.

## React Version
Create a reusable `ProgramCard` component and render cards from data.

## Acceptance Criteria
- All six programs display correctly.
- Cards have consistent dimensions where appropriate.
- Responsive layout works.
- No duplicated unnecessary markup in React.
